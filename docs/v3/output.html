Output Format Specification

The kschema-pull-methods function extracts endpoint details from backend route files and returns an array of objects. Below is a detailed breakdown of each property returned in the result array.

filePath
String
The absolute file path of the end-points.js router file where the endpoint route config was detected.
Example Value
"D:\\KeshavSoftRepos\\kschema-pull-methods\\test\\v10\\api\\v1\\doctors\\end-points.js"
line
String
The full, raw string content of the exact line in the backend file matching the routing declaration pattern.
Example Value
"router.get('/showAll', (req, res) => funcFromshowAll({ req, res }));"
lineNumber
Number
The 1-indexed line number in the router file where the matched route statement is declared.
Example Value
14
funcToRun
String
The name of the backend controller/handler function invoked when this route is requested. Typically starts with the prefix funcFrom.
Example Value
"funcFromshowAll"
endPoint
String
The relative HTTP endpoint URL path defined in the router statement, excluding any leading slash. Can include path variables (e.g. :pk).
Example Value
"showAll"
method
String
The HTTP verb configured for the route (e.g., get, post, put, delete, patch), outputted as a lowercase string.
Example Value
"get"
forRestClient
String
The computed base REST routing path relative to the base target directory (inTargetPath). Useful for automatically configuring REST client requests or testing tools.
Example Value
"/api/v1/doctors"
JSON Result Structure
[
  {
    "filePath": "D:\\...\\end-points.js",
    "line": "router.get('/showAll', ...);",
    "lineNumber": 14,
    "funcToRun": "funcFromshowAll",
    "endPoint": "showAll",
    "method": "get",
    "forRestClient": "/api/v1/doctors"
  }
]
